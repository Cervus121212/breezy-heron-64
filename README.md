A program that writes one original sentence (91 characters) about a hilariously useless superpower: it can read minds, but only pigeons', and every single one of them is thinking about crumbs.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
